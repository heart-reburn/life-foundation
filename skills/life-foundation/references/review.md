# Reviews

## Weekly (10 minutes)

1. Read the week's rows in the progress file.
2. For each practice: how many times did it happen, and what got in the way?
3. Keep it, make it smaller, or swap it. A practice that never happens is too big or badly timed, not a character flaw.
4. Write the plan for next week.

## Quarterly (30 minutes)

1. Count rows per area for the quarter.
2. For each area, rate it: stuck, improving, or steady.
3. List up to three gaps: areas that are stuck and matter now.
4. Pick at most three focus areas for next quarter: one main, one secondary, one to maintain.
5. If the progress file has no rows, there is nothing to review. Restart with one small practice instead.
